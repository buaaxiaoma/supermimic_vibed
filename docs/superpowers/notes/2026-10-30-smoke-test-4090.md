## 结论

1. **纯 torch 路径可用**：世界模型侧测试 `tools/test_analysis_wm.py` 在本机全部通过。
2. **仿真路径在本机不可用**：导入 `TrackingSim` 时崩溃：

   ```
   File ".../isaaclab/actuators/newton/adapter.py", line 503, in LightArticulationView
       _create_actuator_dof_mapping = ArticulationView._create_actuator_dof_mapping
   AttributeError: type object 'ArticulationView' has no attribute '_create_actuator_dof_mapping'.
   Did you mean: '_get_actuator_dof_mapping'?
   ```

   这是本机 Isaac Lab 源码树与已安装 `isaaclab_newton` 版本之间的 API 不一致，**不是本仓库的代码问题**。修复它会改动用户的全局环境，不在本计划范围内。
3. **训练不可在本机跑**：8 GB 显存，基线需 10–20 GB（见计划 §执行环境）。
4. **资产转换可用**：`tools/urdf_to_mjcf.py` 与 Isaac Lab 的 `scripts/tools/convert_mjcf.py` 在本机均成功，生成了 `data/g1_usd/g1_29dof/g1_29dof.usda` 及 `payloads/Physics/mujoco.usda`（与 `G1_CFG` 的 `variants={"Physics": "mujoco"}` 匹配）。
   注意：仓库自带的 `tools/mjcf_to_usd.py` 在本机失败（`No module named 'isaacsim.asset'`），改用 Isaac Lab 官方转换脚本即可。
