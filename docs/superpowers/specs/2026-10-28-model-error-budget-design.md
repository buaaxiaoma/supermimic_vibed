# 可微世界模型驱动的全身控制：误差预算、可辨识性与模型利用

**日期**：2026-10-28（2026-10-30 修订）
**状态**：设计草案 v2，待拍板
**基线代码**：`supermimic_vibed`（SuperMimic 复现，arXiv:2610.28480）

---

## 1. 意图与理由

SuperMimic 用可微世界模型（下称 WM）替代物理仿真器，通过 32 步 BPTT 训练全身跟踪策略，把 40 条 LAFAN1 动作的训练压到单卡 1.2 h（论文数据；本复现为 RTX PRO 6000 上 1.47 h 到 0.829）。速度的来源是**信任 WM**——策略不是在仿真里"活着"，而是在*优化一个模型*。

论文自身没有任何关于模型误差、鲁棒性或安全性的分析。其 §6 limitations 明写：

> "The world model learns only from simulator transitions. Real-robot data could refine it, and its differentiability could support system identification."

因此**"用真实数据改进 WM"不能是本文的 novelty**。ASAP（RSS 2025，arXiv:2502.01143）已在真 G1 全身跟踪上做完整个闭环（真机 rollout → delta 动作模型 → 微调 → 踢腿 E_g-mpjpe 61.2→50.2 mm）；Contact-UAN（arXiv:2610.18991）用 6.5 分钟真机行走修正执行器残差并重训；HALO（arXiv:2603.15084）用 MuJoCo-XLA 梯度辨识真 G1 的质量/CoM/惯量/阻尼/静摩擦；HumanoidNDM（CoRL 2026，arXiv:2610.34126）用真实数据训练神经动力学模型并反传微调策略；LIFT（ICLR 2026，arXiv:2601.21363）闭环但 G1 全身跟踪自述"只完成预训练"。**"闭合这个环"本身已经不是 novelty。**

**本文的 novelty 在于诊断，而不是修正**：把 sim-to-real gap 拆开，量化可微 WM 自身贡献了多少、策略在哪些方向利用了它、哪些方向原则上可闭合。修正作为诊断的推论出现在最后。

### 与最近邻的界限（写作时必须逐条覆盖）

| 工作 | 占住了什么 | 本文的差别 |
|---|---|---|
| ASAP（RSS 2025，2502.01143） | 真 G1 全身跟踪的完整闭环，有真机数字 | 修正是**动作通道的黑箱 delta**，不可解释、不可采样、不可插值；且需动捕做目标 |
| Contact-UAN（2610.18991） | 6.5 min 数据修正执行器残差并重训，重训在修正后的仿真里 | 只修执行器通道，无摩擦/CoM/零位辨识；无 LAFAN1 规模的跟踪评测 |
| HALO（2603.15084） | 真 G1 上梯度辨识惯性参数 + 载荷，从头训 | 不是微调；载荷导向；无大规模动作库评测 |
| HumanoidNDM（CoRL 2026） | 真机模型梯度微调跟踪策略，免动捕 | 模型**替代**仿真器（无被修正的训练模型语义），无物理参数向量可检查 |
| LIFT（ICLR 2026） | 协同微调闭环，物理先验世界模型 | 速度跟踪；G1 全身跟踪只完成预训练 |
| SimDist（2603.15759） | 仿真预训练 WM + 真实数据更新潜动力学 | 规划器在线，非 PPO/BPTT 人形跟踪 |
| RWM-U（2504.16680） | 真实数据进 WM，G1 部署 | 速度运动；PPO 想象训练，非 BPTT |
| IDTD（2610.10905） | 用 Fisher 信息/Schur 补算"哪段轨迹能辨识哪些参数" | 问的是轨迹激励；本文问的是**给定可微 WM + 传感器，哪些方向可恢复、哪些被 WM 吸收** |

**边界句**：没有已发表工作在**一个学出来的可微世界模型内**完成"真实数据 → ξ 物理参数辨识 → BPTT 重训 → 真机跟踪改善"的闭环。ASAP/Contact-UAN 修的是通道，HALO 修的是仿真器参数但不开微调，HumanoidNDM 换掉仿真器。

### 为什么这个题目只有这个设置能做

需要**同时存在**：真实机器人（含动捕真值）、物理仿真器、由该仿真器蒸馏出的可微 WM。HumanoidNDM 没有第三个；ASAP/Contact-UAN 没有第三个；NeRD（CoRL 2025）有第三个但未重训策略。

ξ 是**有名字的物理量**（扩展后见 §4.0），这让"模型不准"与"策略依赖某个特定错误参数"可以被分开测量。这是相对所有潜变量世界模型工作的结构性优势。

## 2. 目标 / 非目标 / 反目标

### 目标

- **G0**：把 ξ 从 33 维扩展到能表达真实 sim-to-real 主因的参数化（见 §4.0）。这是其余一切的前提。
- **G1**：三方误差预算——真实 / 仿真 / WM——在**同一状态空间**、按分量与时间跨度分解。有动捕真值，三项两两可比（§4.1）。
- **G2**：ξ 的**可辨识性**：给定传感器组合，哪些方向能从数据中恢复，哪些被 WM 用其他坐标吸收（§4.2）。
- **G3**：量化"模型利用"：`∂J_wm/∂ξ` 与 `∂J_sim/∂ξ` 的差异；检验 H=32 是否越过理论安全视界；用 WM 梯度做最坏 ξ 搜索（§4.3）。
- **G4**：依据 G1–G3 设计一次**有针对性**的真机采集与 ξ\* 辨识，重训，真机验证，并检验 G3 的敏感度差异是否预测了真机失败（§4.4）。

### 非目标

- 不主张 WM 架构创新（SuperDyno、SuperTrack 在前）。
- 不主张"用真实数据改进模型"（见 §1）。
- 不做地形、物体交互、loco-manipulation。
- 不追求超过 SuperMimic 的训练速度或跟踪精度。

### 反目标（即使技术成立也算失败）

- **只交出漂亮的误差曲线，没有可操作结论。** 必须能回答"有限的真机采集该花在哪个方向"。
- **G4 的改善无法归因。** 若提升不能追溯到 G1–G3 指出的具体方向，就是在跑一个更复杂的 ASAP。
- **结论依赖单一动作或单一随机种子。** 可辨识性与敏感性必须在走/跑/跳/摔倒爬起/格斗上一致或明确说明不一致。
- **可辨识性结论建立在错误的参数化上。** 若 ξ 里根本没有承载 gap 的量（见 §4.0），那"不可辨识"只是在说参数化不对。

## 3. 约束

### 硬件

| 项 | 事实 | 影响 |
|---|---|---|
| 算力 | 远程 8× RTX 4090（24 GB，无 NVLink），**环境已配好** | 单次训练缩规模；实验为"多次中等训练并行"，每卡一跑 |
| 真机 | Unitree G1 29-DoF，可自由实验 | G4 完整硬件验证 |
| 动捕 | **marker 式光学动捕**（机器人身上贴反光球，Vicon/OptiTrack 一类） | **关键**：根位姿有真值，G1 的 real↔sim 可在完整状态空间对齐；根状态估计误差可从 gap 中分离。注意：速度需由位置差分或模型辅助微分得到；marker 遮挡会造成短时丢帧；marker 布置需固定并在论文中说明 |
| 关节力矩 | **无扭矩传感器**。`tau_est` 为电流推算，受摩擦、反射惯量、kt 温度漂移影响 | 关节摩擦不可直接观测；`tau_est` 只能作带误差的观测量 |

| 感知 | 本体感知 + IMU（500 Hz，raw + fused） | 部署时根状态由估计器或动捕提供 |

**安全**：ASAP 在采集阶段**弄坏了两台 G1**。真机采集必须有吊架、限幅、阻尼/急停模式，且失败检测要自动切阻尼。这是硬前提，不是优化项。

### 软件

- 基线为 Isaac Lab 3 kit-less + MuJoCo-Warp；**4090（Ampere）未验证**——第一件事是 smoke test。
- `train.py` 写死 `cuda:0`；多卡并行靠多进程。
- 真机侧需自建 500 Hz 低层控制循环（`unitree_sdk2py`）。

### 评测基准（2025–26 硬标准）

- **机器人**：Unitree G1 29-DoF 是主平台。
- **动作库**：LAFAN1（77 clips，~4.6 h）是每动作研究的最低门槛；跨规模结论需要更大语料（BONES-SEED 264.56 h 是 SuperMimic 用的）。**retargeter 必须写明（GMR 是默认）**——retargeter 选择本身能移动成功率几十个点。
- **失败判据**：SONIC 的"根或末端高度偏差 > 0.25 m"是 2026 新标准（ASAP 时代用 0.5 m），必须显式声明。
- **指标**：14 link 的 MPJPE-L（mm）；或 BeyondMimic 系 E_g-mpbpe/E_mpjpe/E_vel；分上下身；长时域存活率。
- **协议**：sim 100 trials（无 DR）/ sim-dr 4096 / sim2sim 100（另一引擎）；真机小 N（SONIC 124 动作，ASAP 30 次/任务）。**必须报次数与失败判据。**
- **强制 baseline**：SONIC（arXiv:2511.07820）、BeyondMimic（arXiv:2508.08241）；触及 sim-to-real 修正则必须比 ASAP。

## 4. 各部分怎么运作

### 4.0 参数化扩展（G0，前提）

**现状**（`env.py`）：ξ = [接触摩擦 μ (1), 关节零位 (29), 躯干 CoM (3)]。注意三件事：

1. **ξ[0] 是 MuJoCo 的接触滑动摩擦**（写进 `shape_material_mu`），**不是关节摩擦**。关节的 `frictionloss`/`damping`/`armature`/背隙不在 ξ 中，也从未被扰动。
2. 地面 μ 固定，MuJoCo 取配对 `max` → 有效 μ = ξ[0] 仅当 ξ[0] ≥ 0.3，**对抗搜索的下半段从构造上是死区**。
3. 摩擦与 CoM 是**构造时采样一次**、不按 episode 重采样；只有关节零位逐 episode 重采。

**扩展方案（纳入本工作）**：在 ξ 中加入

- 每关节 `frictionloss` 与 `damping`（29×2），
- 每关节 `armature` 缩放（29）或至少按电机型号分类的 4 组，
- 执行器延迟 / 一阶滞后（1–2），
- 每脚接触摩擦（2）或按脚分组。

**代价**：ξ 维度变化 → WM 输入维度变化 → **现有 checkpoint 作废，基线重训**。现有复现结果仅作参考基线，不参与主实验对比。这是被明确接受的代价。

**为什么必须做**：若不扩展，"可辨识性"结论有一半是在陈述"这 33 维里没有真正要找的东西"——那是对参数化的批评，不是对方法的贡献。

### 4.1 三方误差预算（G1）

**机制**：同一策略、同一动作、同一初始状态、同一动作序列，在三个世界里 rollout：

- **仿真 ↔ WM**：从同一 `S_0` 逐步 rollout，比较 `S_t`。第一层 gap，完整可测。
- **真实 ↔ 仿真**：真机与仿真的同一动作序列，比较**完整状态空间**——`q, qd` 直接测，`p, R` 由 marker 光学动捕提供真值，`v, w` 由动捕位置差分（或模型辅助微分）得到，须说明微分噪声的处理方式。
- **真实 ↔ WM**：把 WM 初始化在真实状态（动捕提供），用真实动作序列 open-loop 推演，与动捕测得的未来状态比较。这是标准的多步预测评测，**在有动捕后变得合法且可做**。

**动捕的已知限制**（必须写进论文）：marker 遮挡导致短时丢帧，需插值并报告丢帧比例；位置差分放大噪声，速度误差可能主导该分量；marker 布置（躯干几个点、是否加脚部）决定姿态精度，需固定并说明。**动捕只用于评估与离线分析，不进入部署回路**——否则"免动捕部署"的声明不成立。

**度量**：全部在状态空间，按六个分量（位置、朝向、线速度、角速度、关节位置、关节速度）× 时间跨度（1 / 8 / 32 / 更长）分解，用与 `wm.out_norm` 一致但**以物理单位报告**的归一化（两者都给，见 §4.2 末）。

**明确声明**：三项两两比较，**不假设可加性**。非线性系统里 `E[real↔sim] + E[sim↔WM] ≠ E[real↔WM]`，所以论文报告三对差值并解释非可加项，而不是给一个"比例"。这是可以辩护的表述；给一个相加的百分比不能。

**产出**：误差随视界增长的曲线，指出 WM 在 H=32 时的误差量级与来源分量；以及**仿真器执行器模型误差**（见下）作为**具名、不与任何 ξ 方向对应的独立分量**。

**执行器模型的独立缺口**：`robot.py` 用 armature 推出的 kp/kd（10 Hz 自然频率、阻尼比 2）、implicit PD、4 子步（250 Hz）；真机是 500 Hz、Unitree 自己的增益。这与 WM 的 50 Hz 离散化是**两个独立的缺口**。不把仿真器执行器模型校准到真机（否则基线 checkpoint 失效），而是把该缺口作为预算中的具名分量报告。

### 4.2 可辨识性（G2）

**必须区分两个不同的量，且以第二个为headline：**

- **(a) WM 的条件敏感度**：`L(ξ)` 对 ξ 的 Jacobian/Fisher，在 WM 自身。便宜（几小时，autograd），但只说明"WM 依赖哪些方向"，**不是**"数据能否恢复 ξ"。若 WM 对某方向盲，该方向在 (a) 下"不可辨识"，而仿真器可能高度敏感——这会让"不可辨识但重要"的格子填满 **WM 盲区**，那是 G3 的结论，不是 G2 的。
- **(b) 从数据中的可恢复性**：给定传感器组合（`q, qd`、IMU、`tau_est`、可选动捕根状态），以物理真值（仿真重仿真或真机+动捕）为参照，ξ 的后验是否收窄。这是系统辨识问题，也是"给定传感器组合"唯一说得通的含义。代价高（需重仿真/真实数据）。

**G2 的主张以 (b) 为准；(a) 作为廉价诊断并喂给 G3。**

**关键交叉**：可恢复性 (b) × 物理重要性（在仿真里扰动该方向对 `J` 的影响）。四个格子：

| | 可恢复 | 不可恢复 |
|---|---|---|
| **重要** | 用真机数据拟合（G4 的采集目标） | **诊断核心**：是 WM 盲区、传感器缺失，还是仿真器结构缺陷 |
| **不重要** | 拟合了也没用 | 忽略 |

**物理先验（必须检验，不可当结论）**：真机 500 Hz PD、仿真 250 Hz 求解、WM 50 Hz 离散；关节摩擦/阻尼/armature/延迟均不在原 ξ 中。因此预期"重要但不可恢复"的格子非空，且原因可分解。

**Friction 的可观测性**：无足底力、无扭矩真值 → 接触 μ 与关节摩擦都不能直接观测，只能通过接触丰富动作的动力学间接恢复；`tau_est` 自身带摩擦与温漂误差。这一点必须作为 G2 的结论报告，而不是实验失败。

**损失度量**：同时报告 `out_norm` 归一化 + `ERR_FLOOR` 的损失与物理单位损失。两者给出的逐分量可辨识性不同（物理单位下 `qd` 会主导），必须都给并说明差异。

**产出**：ξ 方向 × 动作类别的可恢复性热图 + 重要性格子图 + 不可恢复方向的成因分解。

### 4.3 模型利用（G3）

**指标**：对一组 ξ 扰动 `{δ}`，比较

```
J_sim(ξ + δ)  — 在 MuJoCo 中跑策略的真实收益
J_wm (ξ + δ)  — 在 WM 中跑同一策略的预测收益
```

`∂J_wm/∂ξ` 与 `∂J_sim/∂ξ` 的差异即策略"看到的世界"与真实世界的差异。

**必须避免的陷阱**：WM 每个迭代都在**当前策略**的 ring buffer 上重训（`buffer_steps=1000`），且 `J_wm` 与 `J_sim` 使用同一解析奖励。在训练分布上测，等于问一个刚被训过的模型它记不记得。因此：

- 敏感性对比在**留出的 checkpoint**（非当前训练策略）与**参考动作状态**（构造上 off-distribution）上进行；
- 除 `ΔJ` 外，另报告 **WM 误差与策略所选动作/状态的相关性**——一个 ξ 盲的策略也可能对某方向不敏感，原因与利用无关。

**视界扫描（检验 safe horizon）**：
- H ∈ {8, 16, 32, 64}，每个 H **从头重训**。
- **固定 clip 子集**：H=32 用于过滤合法起点（`f+HZ ≤ clip_end`），故不同 H 的可用起点与动作子集不同。必须取交集，消除该混淆。
- **视界匹配的 sim 目标**：从**同一初始状态、同一参考帧**截断 H 步，用**同一解析奖励、无 critic**。不混入 critic bootstrap 与软终止。
- 另报 `evaluate.py` 的整段归一化收益作为硬件可比指标。

**受控模型误差**：
- 「较少训练数据」不是自由旋钮——WM 在固定大小的 ring buffer 上训练。需显式改变 `buffer_steps`/`wm_batches`/`wm_only_iters`，且这些同时改变策略的暴露。
- **因果实验的协议**：先用受控预算把 WM 训到指定质量，然后**冻结 WM**，**从头重训策略**、其余预算一致。这是算法改动，必须在论文中明说；它不同于主实验的训练流程。
- 「旧 checkpoint」把不同 WM 与不同策略耦合，不作为因果证据；「缩小容量」不做（见 §5）。

**对抗 ξ 搜索**：用 WM 梯度沿 ξ 上升找最坏上下文，对比均匀 DR（`U[0.3,1.2]` 等）。**注意死区**：若保留原接触 μ 参数化，有效 μ = max(地面 μ, ξ[0])，ξ[0] < 0.3 无效——扩展参数化后需重新界定搜索域。文献确认该方向空缺：唯一做过参数空间梯度对抗的是 WR2L（arXiv:1907.13196，2019，MuJoCo benchmark）；2025–26 要么采样（DR/PolySim）、要么力空间扰动策略（RARL、H-infinity）、要么扰动权重（SHAC-ASAM）。

**产出**：敏感度差异图 + 视界-收益曲线 + 对抗 ξ vs 均匀采样。

### 4.4 有针对性修正（G4）

**顺序不可颠倒**：先有 4.1–4.3，再设计采集。

**修复循环论证**：若只用 WM 拟 ξ\*，而 G3 的假设正是 WM 在某些方向盲，则 ξ\* 会在论文最关心的轴上带偏，"用 ξ\* 重训改善了真机"无法归因。

**协议**：ξ\* **同时对两个模型拟合**——

1. 对 **WM**：多步预测误差最小化；
2. 对 **MuJoCo 重仿真**：用记录的动作序列重放，拟合（物理真值，可同时拟合执行器模型参数）。

**两者不一致本身是 G3 的结果**，且是论文更强的主张：从"我们拟合得更好"变成"WM 与物理对同一数据的解释分歧揭示了什么"。

**其余步骤**：
- 采集设计依据 4.2（可恢复且重要）与 4.3（WM 盲区）。
- 真机：`q, qd, tau_est`, IMU, **动捕根状态**。
- 用 ξ\* 更新 WM（重训或条件化），重训策略。
- 真机验证：原始 / 修正后 / 对抗 ξ 鲁棒化，三组对照。**报 trial 数、失败判据（0.25 m）、MPJPE-L。**

**归因要求**：改善必须能追溯到 4.2/4.3 指出的具体方向；若来自未预期方向，如实报告为发现。

- 4.3 受控实验中 WM 质量的定量控制方式（训练步数/数据量/batch），以能稳定复现目标误差为准。

| **ξ 扩展引入新不可辨识方向，稀释结论** | 可恢复性图本来就是按方向分层的，稀释会在图上显示为更多"不可恢复"格——这是结果，不是失败。 |

## 8. 最小可证伪实验（建议先做）

**前置**：环境已配好，但**这台机器上没有 `data/`、没有 checkpoint**。所以第零步是在远程 4090 机器上跑通 smoke test 并产出基线 checkpoint（含扩参前的 33 维版本作为对照）。

**实验**：ξ 扰动的敏感性对比。

- 在**留出的 checkpoint** 与**参考动作状态**（off-distribution）上，逐方向施加同量级扰动，测 `ΔJ_sim` 与 `ΔJ_wm`。
- 同时报告 WM 误差与策略动作/状态的相关性，避免把"策略对某方向天然不敏感"误读为"WM 被利用"。
- 若两者结构明显不同（例如 WM 对某方向几乎无感而仿真敏感）→ 核心论点成立。
- 若高度一致 → 换靶心（见 §6 第三行）。

**成本**：环境就绪后 2–3 天。**信息量**：决定整篇论文的真假。
